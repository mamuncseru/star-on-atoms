# The Ledger

Every claim this book measures, one row each. Rows are appended when a
protocol reaches **REPORTED**, never before — a verdict written ahead of
the experiment that produces it is an opinion with a table around it.

**The four verdicts**, used unchanged for the whole book:

| Verdict | Means |
|---|---|
| **CONFIRMED** | The pre-registered criterion passed, at the registered budget |
| **REFUTED** | The pre-registered criterion failed, and the failure is not a power problem |
| **UNDERPOWERED** | The run could not resolve the question at its budget; not a null result |
| **SUPERSEDED** | A later protocol replaced this one; the row stays, with a pointer |

**"What would change it" is mandatory.** Every row names the specific
result that would overturn it. "Further work" is not an answer.
